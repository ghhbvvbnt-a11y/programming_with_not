# Not Programming — منصة تعليم البرمجة

منصة تعليمية لتدريس البرمجة، عبارة عن ملف HTML واحد مبني بالكامل على **Firebase** (بدون سيرفر خاص، وبدون بناء/Build step).

## المميزات
- تسجيل دخول للطلاب والمعلم (Firebase Authentication).
- كورسات مقسّمة حسب السنة الدراسية ولغة البرمجة.
- محتوى كل كورس: فيديو / ملف PDF / **امتحان** (إما أسئلة اختيار من متعدد داخل الموقع بتصحيح أوتوماتيكي، أو رابط خارجي زي Google Forms).
- نظام دفع يدوي (فودافون كاش / إنستاباي) مع مراجعة المعلم للإيصالات.
- رسائل مباشرة بين الطالب والمعلم (بحد أقصى 3 رسائل أسبوعيًا للطالب).
- مساعد ذكاء اصطناعي للبرمجة داخل الموقع (عبر Cloudflare Worker كـ proxy).
- دعم 3 لغات: العربية / English / Français، ووضع ليلي/نهاري.
- كل البيانات لحظية (real-time) عبر Firestore — أي عدد من الطلاب والأجهزة يشوفوا نفس التحديثات فورًا.

## هيكل الملفات
| الملف | الوظيفة |
|---|---|
| `index-4.html` | الموقع بالكامل (واجهة + منطق الفرونت إند) — الملف اللي بترفعه على الاستضافة |
| `firestore.rules` | صلاحيات قاعدة بيانات Firestore |
| `storage.rules` | صلاحيات تخزين الصور والملفات |
| `ai-proxy-worker-1.js` | كود الـ Cloudflare Worker اللي بيوصل الموقع بالمساعد الذكي |
| `SETUP.md` | خطوات الإعداد التفصيلية خطوة بخطوة على Firebase Console |

## خطوات التشغيل (ملخّص — التفاصيل الكاملة في `SETUP.md`)
1. فعّل **Authentication → Email/Password** في مشروع Firebase.
2. أنشئ **Firestore Database** والصق فيها محتوى `firestore.rules` من تبويب Rules.
3. فعّل **Storage** والصق فيه محتوى `storage.rules`.
4. ارفع `index-4.html` على أي استضافة (GitHub Pages / Firebase Hosting / غيرها).
5. سجّل دخول بحساب المعلم — يتنشئ تلقائيًا أول مرة.

## آخر الإصلاحات
- ✅ حل مشكلة **فشل إضافة الامتحان**: كان نوع المحتوى ("امتحان") بيترجع بصريًا لـ "فيديو" بعد أي تحديث لحظي، فيفشل الحفظ بصمت.
- ✅ إضافة إمكانية استخدام **رابط خارجي** للامتحان (زي Google Forms) — كانت غير متاحة فعليًا من الواجهة رغم ذكرها في `SETUP.md`.
- ✅ حل فقدان بيانات نموذج **إنشاء كورس جديد** (الوصف/السعر/السنة/اللغة وصورة الغلاف) عند الحفظ.
- ✅ تصحيح مشكلة قد تتسبب في تسجيل **إجابة خاطئة كإجابة صحيحة** لو سؤال الامتحان فيه اختيار فاضي.
- ✅ منع فتح **كورس غير مقصود** لطالب عند الضغط على "فتح كورس" في حالة حدوث تحديث لحظي في نفس اللحظة.
